## What's changed

- **Session cookie.** The tag in the session cookie that ties it to the current password is now an HMAC with the panel's secret key instead of a plain SHA-256 of the password, so a stolen cookie gives nothing to test password guesses against. Everyone signs in again once after the update.

- **Tab from the address.** An address such as `…/#toString` no longer breaks the page: an unknown tab opens "Overview".

## Update

**System → Update** in the panel (since 1.4.0), or on the server:

    awg-router update

New install (Ubuntu or Debian, as root):

    curl -fsSL https://raw.githubusercontent.com/r-slashslash/AWG-Router/main/install.sh | bash

## Что изменилось

- **Cookie сессии.** Метка в cookie сессии, которая привязывает её к текущему паролю, теперь считается как HMAC с секретным ключом панели, а не как голый SHA-256 от пароля: по украденному cookie нельзя проверять догадки о пароле. После обновления всем нужно один раз войти заново.

- **Вкладка из адреса.** Адрес вида `…/#toString` больше не ломает страницу: неизвестная вкладка открывает «Обзор».

    awg-router update

## 改动

- **会话 Cookie。** 会话 Cookie 中将其与当前密码绑定的标记，现在使用面板密钥计算的 HMAC，而不是密码的普通 SHA-256：被盗的 Cookie 无法用来验证猜测的密码。更新后所有人需要重新登录一次。

- **地址中的选项卡。** 类似 `…/#toString` 的地址不再导致页面出错：未知的选项卡会打开「概览」。

## 更新

在面板中 **系统 → 更新**（从 1.4.0 起），或在服务器上运行：

    awg-router update

全新安装（Ubuntu 或 Debian，以 root 运行）：

    curl -fsSL https://raw.githubusercontent.com/r-slashslash/AWG-Router/main/install.sh | bash
