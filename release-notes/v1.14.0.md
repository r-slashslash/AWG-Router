## What's new

- **Panel domain.** The installer asks for a domain for the panel; press Enter to keep opening it by IP. Later it can be changed in **System → Domain and certificate**. The panel checks that the domain points to this server. Client configs keep the server's address.
- **Your own certificate.** In the same window you can give the paths to a certificate and key on the server, for example from certbot. The panel checks that the certificate is for the panel address and that the key matches, and picks up a renewed certificate by itself.
- **Port 80 already taken by nginx or Apache.** Before, the panel stayed on a temporary certificate. Now Let's Encrypt validates the panel through that web server: the panel adds its own small file that answers only the validation for the panel address, so your sites don't change. It shows the file and asks first, tests the config before the reload, and removes the file on any error. nginx on the host or in Docker and Apache on the host are set up automatically; for other web servers the panel shows the block to add by hand. Thanks to Neborya (#4).

## What's fixed

- **QR codes scan reliably in AmneziaWG on Android.** QR codes in the panel (client connection, app install, two-factor setup) and on a client's personal page are now drawn as a sharp picture where every square has the same whole number of screen pixels. Before, squares came out of different sizes with blurred edges, and the AmneziaWG scanner on Android often failed to read the code or needed many tries. In the dark theme the white margin around a QR code is wider, because the phone camera overexposes a thin one, but it only takes free space: the code itself keeps its size. Thanks to koo-pub.

## Что нового

- **Домен панели.** Установщик спрашивает домен для панели; Enter — панель по-прежнему открывается по IP. Потом его можно сменить в **«Система» → «Домен и сертификат»**. Панель проверяет, что домен указывает на этот сервер. Адрес в конфигах клиентов не меняется.
- **Свой сертификат.** В том же окне можно указать пути к сертификату и ключу на сервере, например от certbot. Панель проверит, что сертификат выдан на адрес панели и ключ к нему подходит, и сама подхватит продлённый сертификат.
- **Порт 80 уже занят nginx или Apache.** Раньше панель оставалась с временным сертификатом. Теперь Let's Encrypt проверяет панель через этот веб-сервер: панель добавляет свой маленький файл, который отвечает только на проверку для адреса панели, поэтому ваши сайты не меняются. Она сначала показывает файл и спрашивает, проверяет конфиг перед перезагрузкой и при любой ошибке удаляет файл. nginx на хосте или в Docker и Apache на хосте настраиваются сами; для других веб-серверов панель показывает блок, который нужно вставить вручную. Спасибо Neborya (#4).

## Что исправлено

- **QR-коды надёжно сканируются в AmneziaWG на Android.** QR-коды в панели (подключение клиента, установка приложения, настройка двухфакторного входа) и на личной странице клиента теперь рисуются чёткой картинкой, где каждый квадратик занимает одинаковое целое число пикселей экрана. Раньше квадратики получались разного размера с размытыми краями, и сканер AmneziaWG на Android часто не читал код или читал только с многих попыток. В тёмной теме белое поле вокруг QR-кода шире, потому что камера телефона пересвечивает тонкое поле, но оно занимает только свободное место: сам код не уменьшается. Спасибо koo-pub.

## 新功能

- **面板域名。** 安装程序会询问面板域名；按 Enter 则继续通过 IP 打开面板。之后可以在 **系统 → 域名和证书** 中修改。面板会检查域名是否指向本服务器。客户端配置中的地址不变。
- **自有证书。** 在同一窗口中可以填写服务器上证书和私钥的路径，例如 certbot 签发的。面板会检查证书是否签发给面板地址、私钥是否匹配，并自动加载续期后的证书。
- **80 端口已被 nginx 或 Apache 占用。** 以前面板只能使用临时证书。现在 Let's Encrypt 会通过该网页服务器验证面板：面板添加一个自己的小文件，只响应面板地址的验证请求，你的网站不受影响。它会先显示文件并征求同意，重新加载前检查配置，出现任何错误都会删除该文件。主机上或 Docker 中的 nginx 以及主机上的 Apache 会自动设置；对于其他网页服务器，面板会显示需要手动添加的配置块。感谢 Neborya（#4）。

## 修复内容

- **AmneziaWG（Android）可以可靠地扫描二维码。** 面板中（客户端连接、安装应用、设置双重验证）和客户端个人页面上的二维码现在以清晰的图片绘制，每个方块占用相同的整数个屏幕像素。以前方块大小不一、边缘模糊，Android 上的 AmneziaWG 扫描器经常无法识别，或需要多次尝试。在深色主题中，二维码周围的白边更宽，因为手机摄像头会使较窄的白边过曝，但白边只占用空余空间：二维码本身的尺寸不变。感谢 koo-pub。

## تازه‌ها

- **دامنهٔ پنل.** نصب‌کننده دامنه‌ای برای پنل می‌پرسد؛ با Enter پنل مثل قبل با IP باز می‌شود. بعداً می‌توان آن را در **سیستم ← دامنه و گواهی** عوض کرد. پنل بررسی می‌کند که دامنه به همین سرور اشاره کند. آدرس در پیکربندی کلاینت‌ها تغییر نمی‌کند.
- **گواهی خودتان.** در همان پنجره می‌توانید مسیر گواهی و کلید را روی سرور بدهید، مثلاً از certbot. پنل بررسی می‌کند که گواهی برای آدرس پنل صادر شده و کلید با آن جور است، و گواهی تمدیدشده را خودش برمی‌دارد.
- **درگاه ۸۰ از پیش در اختیار nginx یا Apache است.** پیش‌تر پنل با گواهی موقت می‌ماند. اکنون Let's Encrypt پنل را از طریق همان وب‌سرور بررسی می‌کند: پنل فایل کوچک خودش را اضافه می‌کند که فقط به اعتبارسنجی آدرس پنل پاسخ می‌دهد، پس سایت‌های شما تغییر نمی‌کنند. اول فایل را نشان می‌دهد و می‌پرسد، پیش از بارگذاری دوباره پیکربندی را می‌آزماید و با هر خطایی فایل را حذف می‌کند. ‏nginx روی میزبان یا در داکر و Apache روی میزبان خودکار تنظیم می‌شوند؛ برای وب‌سرورهای دیگر پنل بخشی را نشان می‌دهد که باید دستی اضافه کنید. سپاس از Neborya ‏(#4).

## اصلاح‌ها

- **کدهای QR در AmneziaWG روی اندروید به‌خوبی اسکن می‌شوند.** کدهای QR در پنل (اتصال کلاینت، نصب برنامه، راه‌اندازی ورود دومرحله‌ای) و در صفحهٔ شخصی کلاینت اکنون به‌صورت تصویری واضح کشیده می‌شوند که هر مربع آن تعداد صحیح و یکسانی از پیکسل‌های صفحه را می‌گیرد. پیش‌تر مربع‌ها اندازه‌های متفاوت و لبه‌های تار داشتند و اسکنر AmneziaWG روی اندروید اغلب کد را نمی‌خواند یا تنها پس از چندین بار تلاش می‌خواند. در پوستهٔ تیره حاشیهٔ سفید دور کد QR پهن‌تر است، چون دوربین گوشی حاشیهٔ باریک را بیش از حد روشن می‌بیند، اما این حاشیه فقط از فضای خالی برداشته می‌شود و خود کد کوچک نمی‌شود. سپاس از koo-pub.
