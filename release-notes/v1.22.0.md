## What's changed

- **Clients can check their access in your Telegram bot.** Every client now has an invitation to the bot (client window → **Connect**). Whoever opens it sees in a private chat with the bot the same as on their personal page — online or not, traffic, end date and limit — and can get their config there (QR code, file and `vpn://` link). Nothing else of the panel is visible to them, and the bot never writes to them first. The switch is **System → Telegram → Clients can check their access in the bot**: on by default; if your bot only sent notifications so far, it stays off until you turn it on. The bot's command menu now shows only in your own chat with it.

- **The personal link is there from the start.** A new client gets its personal link right away, so you don't have to create it. The link and the bot invitation sit together in the client window under **Connect**, next to the QR code and `vpn://`. **Renew link and invitation** replaces both: the old ones stop working, and a Telegram connected with the old invitation is disconnected — use it when a link got to the wrong person. Clients made before 1.22.0 get a **Create link** button.

- **The server's name in the browser tab.** With several servers open you no longer have to look at the address bar: the tab shows the server's address, or a name you give it in **System → Settings → Server name**. Thanks to @MacSergey (#38).

- **Day/night button.** A sun or moon button in the header switches the panel between light and dark; the browser remembers your choice, and the client's personal page follows it too. Without a choice the panel follows your system, as before. Thanks to @paris19891 for the idea (#38).

- **Even rows on a phone.** In the client list on a phone, the exit sits at the right edge in every row, like the month's traffic, instead of shifting from row to row.

- **Telegram notifications no longer go silent when a group becomes a supergroup.** Telegram gives such a group a new number; the panel now picks it up by itself.

- **A clear message when two panels share one bot.** If another program (usually a second panel with the same bot) reads your bot, commands went to one or the other at random. The Telegram settings now say so and suggest a separate bot for each panel.

- **The bot writes errors in words.** Instead of internal codes like `srv.subnet_full` the bot now writes the same sentence the panel shows, in the bot's language.

- **Stronger sign-in with a code.** If someone knows your panel password, wrong codes from the app are now counted from all addresses together: after 10 wrong codes, sign-in with a code is closed for 10 minutes, and you get a Telegram message every time the password was right and the code wasn't — a sign that the password should be changed. Turning the code on now asks for the panel password.

- **Big network lists no longer eat the memory.** A list of networks from a link with hundreds of thousands of lines took hundreds of megabytes while being updated; on a server with 1 GB of memory that could stop the panel. It now takes a few dozen megabytes.

- **Your own AmneziaWG server stays up to date.** If the panel's installer set up its own AmneziaWG server in a container, that container was never updated and ran on a 2023 system without security fixes. It is now built on a current system with the same AmneziaWG as the panel, and **every update of the panel updates it too**. Keys, clients and the port stay the same, configs don't change; VPN pauses for a few seconds during the update. If the new container doesn't start, the old one is started again. A server made by the AmneziaVPN app or a server on the host is not touched.

- **A safer build.** Programs from other projects (AmneziaWG and the SOCKS5 tunnel) and the base systems are now taken by their exact fingerprint, not by version name: if someone swapped the code behind a version name, the build would stop instead of putting that code into a release.

## Update

**System → Update** in the panel (since 1.4.0), or on the server:

    awg-router update

New install (Ubuntu or Debian, as root):

    curl -fsSL https://raw.githubusercontent.com/r-slashslash/AWG-Router/main/install.sh | bash

If the panel installed its own AmneziaWG server in a container, VPN clients lose the connection for a few seconds during this update, while that container is replaced.

**Going back to 1.21.0** works with `AWGR_SRC_URL=https://github.com/r-slashslash/AWG-Router/releases/download/v1.21.0/awg-router.tar.gz awg-router update`; backups made in 1.22.0 load there (the server name and the bot switch are simply ignored). The AmneziaWG container stays on its new image.

## Что изменилось

- **Клиенты могут смотреть свой доступ в вашем боте Telegram.** У каждого клиента теперь есть приглашение в бота (окно клиента → **«Подключение»**). Тот, кто его откроет, видит в личном чате с ботом то же, что на своей личной странице: в сети ли, трафик, срок и лимит, — и может получить там свой конфиг (QR-код, файл и ссылку `vpn://`). Больше ничего из панели ему не видно, и сам бот ему ничего не присылает. Включается в **«Система» → «Telegram» → «Клиенты могут смотреть свой доступ в боте»**: по умолчанию включено; если ваш бот до сих пор только присылал уведомления, это остаётся выключенным, пока вы не включите. Меню команд бота теперь видно только в вашем собственном чате с ним.

- **Личная ссылка — сразу.** У нового клиента личная ссылка появляется сразу, создавать её не нужно. Ссылка и приглашение в бота — вместе в окне клиента, в **«Подключении»**, рядом с QR-кодом и `vpn://`. **«Обновить ссылку и приглашение»** меняет обе: прежние перестают работать, а Telegram, подключённый по прежнему приглашению, отключается, — это на случай, если ссылка попала не тому человеку. У клиентов, созданных до 1.22.0, — кнопка **«Создать ссылку»**.

- **Название сервера во вкладке браузера.** Когда открыто несколько серверов, больше не нужно смотреть в адресную строку: во вкладке — адрес сервера или название, которое вы ему дали в **«Система» → «Настройки» → «Название сервера»**. Спасибо @MacSergey (#38).

- **Кнопка «день/ночь».** Кнопка с солнцем или луной в шапке переключает панель между светлой и тёмной темой; браузер запоминает выбор, и личная страница клиента тоже следует ему. Без выбора панель, как раньше, следует теме системы. Спасибо @paris19891 за идею (#38).

- **Ровные строки на телефоне.** В списке клиентов на телефоне выход в каждой строке стоит у правого края, как трафик за месяц, а не «прыгает» от строки к строке.

- **Уведомления Telegram больше не замолкают, когда группа становится супергруппой.** Telegram даёт такой группе новый номер; панель теперь сама его подхватывает.

- **Понятное сообщение, когда у двух панелей один бот.** Если вашего бота читает другая программа (обычно вторая панель с тем же ботом), команды доставались то одной, то другой. Теперь об этом говорят настройки Telegram и советуют завести каждой панели свой бот.

- **Бот пишет ошибки словами.** Вместо внутренних кодов вроде `srv.subnet_full` бот пишет ту же фразу, что и панель, на языке бота.

- **Вход по коду надёжнее.** Если кто-то знает пароль панели, неверные коды из приложения теперь считаются со всех адресов вместе: после 10 неверных кодов вход по коду закрыт на 10 минут, а вам в Telegram приходит сообщение каждый раз, когда пароль был верный, а код — нет: это знак, что пароль пора сменить. Чтобы включить вход по коду, теперь нужно ввести пароль панели.

- **Большие списки сетей больше не съедают память.** Список сетей по ссылке на сотни тысяч строк при обновлении занимал сотни мегабайт; на сервере с 1 ГБ памяти это могло остановить панель. Теперь — несколько десятков мегабайт.

- **Свой сервер AmneziaWG больше не устаревает.** Если установщик панели поставил свой сервер AmneziaWG в контейнер, этот контейнер никогда не обновлялся и работал на системе 2023 года без исправлений безопасности. Теперь он собирается на свежей системе, с той же AmneziaWG, что и панель, и **обновляется при каждом обновлении панели**. Ключи, клиенты и порт остаются прежними, конфиги не меняются; на время обновления VPN прерывается на несколько секунд. Если новый контейнер не запустится, снова запускается прежний. Сервер, поставленный приложением AmneziaVPN, и сервер на самом VPS это не затрагивает.

- **Сборка надёжнее.** Программы других проектов (AmneziaWG и туннель для SOCKS5) и основы систем теперь берутся по точному отпечатку, а не по названию версии: если бы кто-то подменил код под названием версии, сборка остановилась бы, а не взяла этот код в выпуск.

## تغییرها

- **کاربران می‌توانند دسترسی خود را در ربات تلگرام شما ببینند.** اکنون هر کاربر یک دعوت به ربات دارد (پنجرهٔ کاربر ← **اتصال**). هر کس آن را باز کند، در گفت‌وگوی خصوصی با ربات همان چیزی را می‌بیند که در صفحهٔ شخصی‌اش هست — آنلاین است یا نه، ترافیک، مهلت و سقف — و می‌تواند پیکربندی‌اش را همان‌جا بگیرد (کد QR، فایل و پیوند <bdi>`vpn://`</bdi>). چیز دیگری از پنل برایش دیده نمی‌شود و ربات خودش چیزی برایش نمی‌فرستد. کلید آن در **سیستم ← تلگرام ← کاربران می‌توانند دسترسی خود را در ربات ببینند** است: به‌طور پیش‌فرض روشن است؛ اگر ربات شما تا حالا فقط اعلان می‌فرستاد، خاموش می‌ماند تا خودتان روشنش کنید. منوی فرمان‌های ربات اکنون فقط در گفت‌وگوی خود شما با آن دیده می‌شود.

- **لینک شخصی از همان ابتدا.** کاربر تازه بی‌درنگ لینک شخصی دارد و لازم نیست آن را بسازید. لینک و دعوت ربات با هم در پنجرهٔ کاربر، بخش **اتصال**، کنار کد QR و <bdi>`vpn://`</bdi> هستند. **تازه کردن پیوند و دعوت** هر دو را عوض می‌کند: قبلی‌ها دیگر کار نمی‌کنند و تلگرامی که با دعوت قبلی وصل شده جدا می‌شود — برای وقتی که لینک به دست کس دیگری افتاده است. کاربرانی که پیش از 1.22.0 ساخته شده‌اند دکمهٔ **ساخت لینک** دارند.

- **نام سرور در زبانهٔ مرورگر.** وقتی چند سرور باز است، دیگر لازم نیست به نوار نشانی نگاه کنید: زبانه نشانی سرور یا نامی را نشان می‌دهد که در **سیستم ← تنظیمات ← نام سرور** به آن داده‌اید. با سپاس از @MacSergey (&lrm;#38&lrm;).

- **دکمهٔ روز/شب.** دکمهٔ خورشید یا ماه در سربرگ پنل را میان پوستهٔ روشن و تیره جابه‌جا می‌کند؛ مرورگر انتخاب شما را به خاطر می‌سپارد و صفحهٔ شخصی کاربر هم از آن پیروی می‌کند. بدون انتخاب، پنل مثل قبل از پوستهٔ سیستم پیروی می‌کند. با سپاس از @paris19891 برای این ایده (&lrm;#38&lrm;).

- **ردیف‌های مرتب روی گوشی.** در فهرست کاربران روی گوشی، خروجی در هر ردیف مثل ترافیک ماه در لبهٔ کناری قرار می‌گیرد و دیگر از ردیفی به ردیف دیگر جابه‌جا نمی‌شود.

- **اعلان‌های تلگرام وقتی گروه به سوپرگروه تبدیل می‌شود دیگر خاموش نمی‌شوند.** تلگرام به چنین گروهی شمارهٔ تازه می‌دهد؛ پنل اکنون خودش آن را برمی‌دارد.

- **پیام روشن وقتی دو پنل یک ربات دارند.** اگر برنامهٔ دیگری (معمولاً پنل دومی با همان ربات) ربات شما را بخواند، فرمان‌ها گاهی به یکی و گاهی به دیگری می‌رسیدند. اکنون تنظیمات تلگرام این را می‌گویند و پیشنهاد می‌کنند هر پنل ربات خودش را داشته باشد.

- **ربات خطاها را با کلمه می‌نویسد.** ربات به‌جای کدهای درونی مانند <bdi>`srv.subnet_full`</bdi> همان جمله‌ای را می‌نویسد که پنل نشان می‌دهد، به زبان ربات.

- **ورود با کد امن‌تر.** اگر کسی گذرواژهٔ پنل را بداند، کدهای نادرست برنامه اکنون از همهٔ نشانی‌ها با هم شمرده می‌شوند: پس از ۱۰ کد نادرست، ورود با کد ۱۰ دقیقه بسته می‌شود و هر بار که گذرواژه درست و کد نادرست بود، پیامی در تلگرام می‌گیرید — نشانه‌ای که باید گذرواژه را عوض کنید. روشن کردن ورود با کد اکنون گذرواژهٔ پنل را می‌خواهد.

- **فهرست‌های بزرگ شبکه دیگر حافظه را نمی‌بلعند.** فهرست شبکه‌ای از یک پیوند با صدها هزار سطر هنگام به‌روزرسانی صدها مگابایت می‌گرفت؛ روی سروری با ۱ گیگابایت حافظه این می‌توانست پنل را متوقف کند. اکنون چند ده مگابایت.

- **سرور AmneziaWG خودتان به‌روز می‌ماند.** اگر نصب‌کنندهٔ پنل سرور AmneziaWG خودش را در یک کانتینر نصب کرده بود، آن کانتینر هرگز به‌روز نمی‌شد و روی سیستمی از ۲۰۲۳ بدون وصله‌های امنیتی کار می‌کرد. اکنون روی سیستمی تازه و با همان AmneziaWG پنل ساخته می‌شود و **با هر به‌روزرسانی پنل به‌روز می‌شود**. کلیدها، کاربران و درگاه همان می‌مانند و پیکربندی‌ها عوض نمی‌شوند؛ در زمان به‌روزرسانی VPN چند ثانیه قطع می‌شود. اگر کانتینر تازه بالا نیاید، کانتینر قبلی دوباره روشن می‌شود. سروری که برنامهٔ AmneziaVPN ساخته یا سروری که مستقیم روی میزبان است تغییری نمی‌کند.

- **ساخت امن‌تر.** برنامه‌های پروژه‌های دیگر (AmneziaWG و تونل SOCKS5) و سیستم‌های پایه اکنون با اثر انگشت دقیقشان گرفته می‌شوند، نه با نام نسخه: اگر کسی کد پشت یک نام نسخه را عوض کند، ساخت متوقف می‌شود و آن کد وارد انتشار نمی‌شود.
