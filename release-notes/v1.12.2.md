## What's fixed

**Routing**
- **The exit window keeps your rules.** Saving the routing part of an exit window used to rewrite every rule to that exit: turned-off rules were deleted, rule names were replaced and the rules were merged above other rules. Now an unticked list leaves its rule, a ticked list joins an existing rule to the exit (or a new rule right after them), and everything else stays as it was.
- **Subnet change on a host server.** Changing the subnet of an AmneziaWG server on the host left NAT for the old subnet, so clients had no internet after the restart. NAT now follows the subnet. In an AmneziaVPN container the subnet is written into its start script at install time, so the subnet field there is locked with a note.

**Traffic and limits**
- **Exit quotas count sites from domain rules.** HTTPS and HTTP of clients with domain rules go through the server's own proxy, and the traffic counter did not see it: SOCKS5 exit quotas and the by-exit split of clients missed most of that traffic. The proxy now counts it per client and exit.
- Client and exit limits show when a new month starts in your own time (months follow UTC).

**Reliability**
- **A failing exit is retried with a pause** (10 s growing to 5 min) instead of every 10 s: the event log and Telegram no longer fill up with the same error, and the panel stays responsive. Edit the exit or press **System → Re-apply rules** to retry at once.
- **Restore keeps an exit's own sites list.** Before, after a restore the exit window showed no sites, and saving it created a second list with the same name.
- **Domain rules:** connections through the server's proxy get the same MSS clamp as other traffic (no stalled HTTPS through AmneziaWG exits when path MTU discovery is broken), TCP keepalive and a 15-minute idle timeout (connections of vanished devices no longer pile up).
- The domain list hint now says that QUIC is off for all sites of such clients and that sites with Encrypted Client Hello (ECH) can't be matched by name.

**Updates**
- **Only a released version is installed.** If the release archive can't be downloaded, the installer and the panel's update stop with an error instead of installing unreleased code from the `main` branch. The archive is checked against its `.sha256`.

## Update

**System → Update** in the panel (since 1.4.0), or on the server:

    awg-router update

New install (Ubuntu or Debian, as root):

    curl -fsSL https://raw.githubusercontent.com/r-slashslash/AWG-Router/main/install.sh | bash

## Что исправлено

**Маршрутизация**
- **Окно выхода не трогает ваши правила.** Раньше сохранение маршрутизации в окне выхода переписывало все правила на этот выход: выключенные правила удалялись, подписи заменялись, а правила сливались выше остальных. Теперь снятый список уходит из своего правила, отмеченный добавляется в уже существующее правило на выход (или в новое сразу после них), всё остальное остаётся как было.
- **Смена подсети у сервера на хосте.** После смены подсети сервера AmneziaWG на хосте NAT оставался для старой подсети, и после перезапуска у клиентов пропадал интернет. Теперь NAT меняется вместе с подсетью. У контейнера AmneziaVPN подсеть вписана в его скрипт запуска при установке, поэтому там поле подсети заблокировано с пояснением.

**Трафик и лимиты**
- **Квоты выходов учитывают сайты из правил по доменам.** HTTPS и HTTP клиентов с правилами по доменам идут через собственный посредник сервера, и счётчик трафика их не видел: квоты выходов SOCKS5 и разбивка трафика клиентов по выходам пропускали большую часть такого трафика. Теперь посредник считает его по клиентам и выходам.
- В лимитах клиентов и выходов видно, когда начнётся новый месяц по вашему времени (месяцы считаются по UTC).

**Надёжность**
- **Неработающий выход перезапускается с паузой** (от 10 с до 5 мин), а не каждые 10 секунд: журнал событий и Telegram больше не забиваются одной и той же ошибкой, и панель не подтормаживает. Чтобы попробовать сразу, измените выход или нажмите **«Система» → «Применить правила заново»**.
- **Восстановление из копии сохраняет список сайтов выхода.** Раньше после восстановления окно выхода показывало пустое поле сайтов, а при сохранении появлялся второй список с тем же именем.
- **Правила по доменам:** у соединений через посредник сервера теперь тот же MSS clamp, что и у остального трафика (HTTPS через выходы AmneziaWG не «зависает», если сломан поиск MTU), TCP keepalive и закрытие после 15 минут тишины (соединения пропавших устройств больше не копятся).
- В подсказке к спискам доменов сказано, что QUIC у таких клиентов отключается для всех сайтов, а сайты с Encrypted Client Hello (ECH) по имени не узнать.

**Обновления**
- **Ставится только опубликованная версия.** Если архив релиза не скачался, установщик и обновление из панели останавливаются с ошибкой, а не ставят неопубликованный код из ветки `main`. Архив сверяется с его `.sha256`.

## 修复内容

**路由**
- **出口窗口不再改动你的规则。** 以前在出口窗口中保存路由会重写指向该出口的所有规则：已关闭的规则被删除，规则名称被替换，规则被合并到其他规则之上。现在取消勾选的列表只从其规则中移除，新勾选的列表加入指向该出口的现有规则（或紧随其后的新规则），其余保持不变。
- **主机服务器更改子网。** 以前在主机上更改 AmneziaWG 服务器的子网后，NAT 仍针对旧子网，重启后客户端无法上网。现在 NAT 会随子网一起更改。AmneziaVPN 容器的子网在安装时写入其启动脚本，因此那里的子网字段已锁定并附有说明。

**流量和限额**
- **出口配额计入域名规则中的网站。** 带域名规则的客户端的 HTTPS 和 HTTP 经过服务器自身的代理，流量计数器看不到这部分流量：SOCKS5 出口配额和客户端按出口的流量统计漏掉了其中大部分。现在由代理按客户端和出口统计。
- 客户端和出口的限额会显示新的月份在您的时间何时开始（月份按 UTC 计算）。

**可靠性**
- **故障出口的重试带有间隔**（从 10 秒逐步增加到 5 分钟），而不是每 10 秒一次：事件日志和 Telegram 不再被同一错误刷屏，面板也保持流畅。修改该出口或点击 **系统 → 重新应用规则** 可立即重试。
- **从备份恢复会保留出口自己的网站列表。** 以前恢复后出口窗口中的网站为空，保存时会再创建一个同名列表。
- **域名规则：** 经服务器代理的连接现在与其他流量一样进行 MSS 钳制（路径 MTU 发现失效时，经 AmneziaWG 出口的 HTTPS 不再卡住），并启用 TCP keepalive 和 15 分钟空闲超时（失联设备的连接不再堆积）。
- 域名列表的提示说明：此类客户端的 QUIC 对所有网站关闭，启用 Encrypted Client Hello（ECH）的网站无法按名称识别。

**更新**
- **只安装已发布的版本。** 如果无法下载发布归档，安装程序和面板中的更新会报错停止，而不是安装 `main` 分支中未发布的代码。归档会根据其 `.sha256` 进行校验。

## اصلاح‌ها

**مسیریابی**
- **پنجرهٔ خروجی دیگر به قانون‌های شما دست نمی‌زند.** پیش‌تر ذخیرهٔ بخش مسیریابی در پنجرهٔ خروجی همهٔ قانون‌های آن خروجی را بازنویسی می‌کرد: قانون‌های خاموش حذف می‌شدند، نام قانون‌ها عوض می‌شد و قانون‌ها بالای قانون‌های دیگر ادغام می‌شدند. اکنون فهرستی که تیکش را برداشته‌اید فقط از قانون خودش بیرون می‌رود، فهرست تیک‌خورده به قانون موجودِ آن خروجی (یا قانون تازه‌ای درست پس از آن‌ها) افزوده می‌شود و بقیه همان‌طور می‌ماند.
- **تغییر زیرشبکهٔ سرور روی میزبان.** پس از تغییر زیرشبکهٔ سرور AmneziaWG روی میزبان، NAT برای زیرشبکهٔ قدیمی می‌ماند و پس از راه‌اندازی دوباره کلاینت‌ها اینترنت نداشتند. اکنون NAT همراه زیرشبکه تغییر می‌کند. در کانتینر AmneziaVPN زیرشبکه هنگام نصب در اسکریپت راه‌اندازی نوشته می‌شود، پس آن‌جا فیلد زیرشبکه با یک توضیح قفل است.

**ترافیک و سقف‌ها**
- **سقف خروجی‌ها سایت‌های قانون‌های دامنه را هم می‌شمارد.** HTTPS و HTTP کلاینت‌هایی که قانون دامنه دارند از پراکسی خود سرور می‌گذرد و شمارندهٔ ترافیک آن را نمی‌دید: سقف خروجی‌های SOCKS5 و تفکیک ترافیک کلاینت‌ها بر پایهٔ خروجی بیشتر این ترافیک را از دست می‌دادند. اکنون پراکسی آن را برای هر کلاینت و خروجی می‌شمارد.
- سقف کلاینت‌ها و خروجی‌ها نشان می‌دهد ماه نو به وقت شما کی آغاز می‌شود (ماه‌ها بر پایهٔ UTC هستند).

**پایداری**
- **خروجیِ ازکارافتاده با مکث دوباره راه‌اندازی می‌شود** (از ۱۰ ثانیه تا ۵ دقیقه)، نه هر ۱۰ ثانیه: گزارش رویدادها و تلگرام دیگر با یک خطای تکراری پر نمی‌شوند و پنل روان می‌ماند. برای تلاش فوری، خروجی را ویرایش کنید یا **سیستم ← اعمال دوباره قوانین** را بزنید.
- **بازگردانی از پشتیبان فهرست سایت‌های خروجی را نگه می‌دارد.** پیش‌تر پس از بازگردانی، پنجرهٔ خروجی سایتی نشان نمی‌داد و با ذخیره، فهرست دومی با همان نام ساخته می‌شد.
- **قانون‌های دامنه:** اتصال‌های پراکسی سرور اکنون همان MSS clamp ترافیک دیگر را دارند (HTTPS از خروجی‌های AmneziaWG هنگام خرابی کشف MTU مسیر گیر نمی‌کند)، به‌همراه TCP keepalive و بستن پس از ۱۵ دقیقه بی‌فعالیتی (اتصال‌های دستگاه‌های ناپدیدشده دیگر انباشته نمی‌شوند).
- راهنمای فهرست دامنه اکنون می‌گوید که QUIC برای همهٔ سایت‌های چنین کلاینت‌هایی خاموش است و سایت‌هایی با Encrypted Client Hello (ECH) از روی نام شناخته نمی‌شوند.

**به‌روزرسانی‌ها**
- **فقط نسخهٔ منتشرشده نصب می‌شود.** اگر بایگانی انتشار دانلود نشود، نصب‌کننده و به‌روزرسانی از پنل با خطا متوقف می‌شوند و کد منتشرنشده از شاخهٔ `main` را نصب نمی‌کنند. بایگانی با فایل `.sha256` آن بررسی می‌شود.
