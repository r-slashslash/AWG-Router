## What's changed

- **The connection name in a vpn:// key is just the client's name.** AmneziaVPN showed the connection as "name · server address", but the app shows the server address on its main screen anyway, so the address is no longer repeated in the name. Keys issued earlier keep their old name until they are imported again. Thanks @Neborya for the request (#7).
- **One "Add exit" button.** With no exits yet, the Exits tab showed the button twice: at the top and in the empty card. Now it is only at the top, as on the Clients tab.

## Update

**System → Update** in the panel (since 1.4.0), or on the server:

    awg-router update

New install (Ubuntu or Debian, as root):

    curl -fsSL https://raw.githubusercontent.com/r-slashslash/AWG-Router/main/install.sh | bash

## Что изменилось

- **В ключе vpn:// название подключения — только имя клиента.** AmneziaVPN показывал подключение как «имя · адрес сервера», но адрес сервера приложение и так показывает на главном экране, поэтому в названии он больше не повторяется. У ключей, выданных раньше, название останется прежним, пока их не импортируют заново. Спасибо @Neborya за запрос (#7).
- **Одна кнопка «Добавить выход».** Пока выходов нет, на вкладке «Выходы» кнопка была дважды: наверху и в пустой карточке. Теперь она только наверху, как на вкладке «Клиенты».

## 改动

- **vpn:// 密钥中的连接名称只保留客户端名称。** AmneziaVPN 以前把连接显示为“名称 · 服务器地址”，但应用主界面本来就会显示服务器地址，因此名称中不再重复地址。之前发放的密钥在重新导入前保留旧名称。感谢 @Neborya 的建议（#7）。
- **只保留一个“添加出口”按钮。** 尚无出口时，「出口」选项卡上的按钮出现了两次：顶部和空白卡片中。现在只在顶部，与「客户端」选项卡一致。

## 更新

在面板中 **系统 → 更新**（从 1.4.0 起），或在服务器上运行：

    awg-router update

全新安装（Ubuntu 或 Debian，以 root 运行）：

    curl -fsSL https://raw.githubusercontent.com/r-slashslash/AWG-Router/main/install.sh | bash

## تغییرها

- **نام اتصال در کلید vpn:// فقط نام کلاینت است.** AmneziaVPN اتصال را به شکل «نام · نشانی سرور» نشان می‌داد، اما برنامه نشانی سرور را در صفحهٔ اصلی خود هم نشان می‌دهد، پس دیگر در نام تکرار نمی‌شود. کلیدهایی که پیش‌تر صادر شده‌اند تا وارد کردن دوباره نام قبلی خود را نگه می‌دارند. از @Neborya برای این درخواست سپاسگزاریم (#7).
- **فقط یک دکمهٔ «افزودن خروجی».** وقتی هنوز خروجی‌ای نیست، زبانهٔ «خروجی‌ها» دکمه را دو بار نشان می‌داد: بالا و در کارت خالی. اکنون فقط بالاست، مانند زبانهٔ «کلاینت‌ها».
