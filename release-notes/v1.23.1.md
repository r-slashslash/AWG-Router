## What's changed

- **The clients list no longer fills the browser's memory.** While the **Clients** tab was open, the page kept every row it had redrawn, so it grew without limit: about 70 MB an hour with 50 clients and more than 1 GB an hour with 1000. On a phone the tab got slower and could be closed by the browser. Now the page stays the same size however long it is open.

- **The panel opens faster over a slow link.** Before, every time the panel was opened the browser asked the server about each of its files — 13 extra round trips, which over a slow link (from Russia, China or Iran, or through an SSH tunnel) added up: 1.7 s instead of 1.35 s at 300 ms. Now the browser keeps the panel's files until the next update.

- **Less memory on the server with large domain lists.** After a **Route check**, the panel kept every domain list it had checked in memory until its next restart: a list of 300 000 sites took about 36 MB. Now the check reads the list from disk each time, with the same result.

- **Python 3.15.** The panel now runs on Python 3.15.

## Update

**System → Update** in the panel (since 1.4.0), or on the server:

    awg-router update

New install (Ubuntu or Debian, as root):

    curl -fsSL https://raw.githubusercontent.com/r-slashslash/AWG-Router/main/install.sh | bash

**Going back to 1.23.0** works with `AWGR_SRC_URL=https://github.com/r-slashslash/AWG-Router/releases/download/v1.23.0/awg-router.tar.gz awg-router update`; settings and backups are the same.

## 改动

- **客户端列表不再占满浏览器内存。** 打开 **客户端** 选项卡时，页面会保留每一行重绘过的内容，因此会无限增长：50 个客户端时每小时约 70 MB，1000 个客户端时每小时超过 1 GB。在手机上，选项卡会越来越慢，还可能被浏览器关闭。现在无论打开多久，页面大小都保持不变。

## تغییرها

- **فهرست کلاینت‌ها دیگر حافظهٔ مرورگر را پر نمی‌کند.** وقتی زبانهٔ **کلاینت‌ها** باز بود، صفحه هر ردیفی را که از نو کشیده بود نگه می‌داشت و بی‌پایان بزرگ می‌شد: با ۵۰ کلاینت حدود ۷۰ مگابایت در ساعت و با ۱۰۰۰ کلاینت بیش از ۱ گیگابایت در ساعت. روی گوشی زبانه کند می‌شد و ممکن بود مرورگر آن را ببندد. اکنون هر چقدر هم باز بماند، اندازهٔ صفحه ثابت می‌ماند.

- **پنل روی اتصال کند سریع‌تر باز می‌شود.** پیش‌تر با هر بار باز کردن پنل، مرورگر دربارهٔ تک‌تک فایل‌های آن از سرور می‌پرسید — ۱۳ رفت‌وبرگشت اضافه، که روی اتصال کند (از روسیه، چین یا ایران، یا از راه تونل SSH) جمع می‌شد: با تأخیر ۳۰۰ میلی‌ثانیه ۱٫۷ ثانیه به‌جای ۱٫۳۵ ثانیه. اکنون مرورگر فایل‌های پنل را تا به‌روزرسانی بعدی نگه می‌دارد.

- **حافظهٔ کمتر روی سرور با فهرست‌های دامنهٔ بزرگ.** پس از **بررسی مسیر**، پنل هر فهرست دامنه‌ای را که بررسی کرده بود تا راه‌اندازی دوبارهٔ بعدی در حافظه نگه می‌داشت: فهرستی با ۳۰۰٬۰۰۰ سایت حدود ۳۶ مگابایت جا می‌گرفت. اکنون بررسی هر بار فهرست را از دیسک می‌خواند و نتیجه همان است.

- **Python 3.15.** پنل اکنون روی Python 3.15 اجرا می‌شود.
