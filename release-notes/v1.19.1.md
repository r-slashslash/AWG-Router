## What's changed

- **Interface polish.** The common speed limit panel on the Server tab now spans the full width like the other panels. On the Exits tab there is a gap between the empty hint and the "Direct" card. The QR code is centred when the buttons wrap below it (always the case in the dark theme). "Everything else" on the Routing tab shows "Load balancing" without the scales emoji.

## Update

**System → Update** in the panel (since 1.4.0), or on the server:

    awg-router update

New install (Ubuntu or Debian, as root):

    curl -fsSL https://raw.githubusercontent.com/r-slashslash/AWG-Router/main/install.sh | bash

## Что изменилось

- **Мелкие правки интерфейса.** Панель общего ограничения скорости на вкладке «Сервер» занимает всю ширину, как остальные панели. В списке «Всё остальное» на вкладке «Маршрутизация» у «Балансировки» убран эмодзи с весами.

## 改动

- **界面小幅调整。** 「服务器」选项卡中的总限速面板与其他面板一样占满整个宽度。「出口」选项卡中，空白提示与「直连」卡片之间有了间距。按钮换行到二维码下方时（深色主题下总是如此），二维码居中显示。「路由」选项卡中「其余流量」的下拉项「负载均衡」不再带天平表情符号。

    awg-router update
