## What's changed

- **Release download fallback.** When github.com fails to serve the release archive (on servers in Russia `/releases/download/` sometimes answers HTTP 504), the installer and the update now take the same archive and its checksum through api.github.com, which sends them straight to GitHub's file storage. The checksum is checked as before, and a failed download still never installs unreleased code. Thanks to @LCF30 for the fix (#13).

## Update

**System → Update** in the panel (since 1.4.0), or on the server:

    awg-router update

The update runs the installer that is already on the server, so if it stops with "Could not download the latest release (HTTP 504)", run the new installer once instead (settings are kept); later updates will use the fallback by themselves:

    curl -fsSL https://raw.githubusercontent.com/r-slashslash/AWG-Router/main/install.sh | sudo bash

New install (Ubuntu or Debian, as root):

    curl -fsSL https://raw.githubusercontent.com/r-slashslash/AWG-Router/main/install.sh | bash

## Что изменилось

- **Запасной путь скачивания релиза.** Если github.com не отдаёт архив релиза (на серверах в России `/releases/download/` иногда отвечает HTTP 504), установщик и обновление теперь берут тот же архив и его контрольную сумму через api.github.com, который отправляет их прямо в файловое хранилище GitHub. Контрольная сумма проверяется как раньше, и неудачное скачивание по-прежнему никогда не ставит невыпущенный код. Спасибо @LCF30 за исправление (#13).

## Обновление

**«Система» → «Обновить»** в панели (начиная с 1.4.0) или на сервере:

    awg-router update

Обновление запускает установщик, который уже лежит на сервере, поэтому если оно останавливается с «Could not download the latest release (HTTP 504)», один раз запустите вместо него новый установщик (настройки сохранятся); следующие обновления пойдут запасным путём сами:

    curl -fsSL https://raw.githubusercontent.com/r-slashslash/AWG-Router/main/install.sh | sudo bash

Новая установка (Ubuntu или Debian, от root):

    curl -fsSL https://raw.githubusercontent.com/r-slashslash/AWG-Router/main/install.sh | bash

## 改动

- **版本下载的备用途径。** 当 github.com 无法提供版本压缩包时（在俄罗斯的服务器上，`/releases/download/` 有时返回 HTTP 504），安装程序和更新现在会通过 api.github.com 获取同一个压缩包及其校验和，api.github.com 会将请求直接转到 GitHub 的文件存储。校验和照常检查，下载失败时仍然绝不会安装未发布的代码。感谢 @LCF30 的修复（#13）。

## 更新

    awg-router update

更新使用的是服务器上已有的安装程序，因此如果它因 "Could not download the latest release (HTTP 504)" 而停止，请改为运行一次新的安装程序（设置会保留）；之后的更新会自动使用备用途径：

    curl -fsSL https://raw.githubusercontent.com/r-slashslash/AWG-Router/main/install.sh | sudo bash

全新安装（Ubuntu 或 Debian，以 root 运行）：

    curl -fsSL https://raw.githubusercontent.com/r-slashslash/AWG-Router/main/install.sh | bash

## تغییرها

- **راه جایگزین برای دانلود نسخه.** وقتی github.com بستهٔ نسخه را نمی‌دهد (روی سرورهای روسیه <bdi>`/releases/download/`</bdi> گاهی HTTP 504 برمی‌گرداند)، نصب‌کننده و به‌روزرسانی اکنون همان بسته و چک‌سام آن را از راه <bdi>api.github.com</bdi> می‌گیرند که آن‌ها را مستقیم به فضای ذخیره‌سازی فایل گیت‌هاب می‌فرستد. چک‌سام مثل قبل بررسی می‌شود و دانلود ناموفق همچنان هرگز کد منتشرنشده را نصب نمی‌کند. سپاس از <bdi>@LCF30</bdi> برای این اصلاح (<bdi>#13</bdi>).
