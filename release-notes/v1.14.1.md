## What's changed

- **Client masking list without a duplicate.** In a client's window the masking list showed the server's template twice: as "As on the server: …" and once more as a separate item. Now there is one item, named after the server's template, for example **DNS response: icloud.com (default)**. A client on it gets the server's template, also after you change the template in the server settings.
- **Client route.** The first item of a client's route list was "Same as everyone (now: …)"; it is now **Default “…”** with the current exit's name. It still follows the exit chosen for everyone.

## Update

**System → Update** in the panel (since 1.4.0), or on the server:

    awg-router update

New install (Ubuntu or Debian, as root):

    curl -fsSL https://raw.githubusercontent.com/r-slashslash/AWG-Router/main/install.sh | bash

## Что изменилось

- **Список маскировки клиента без дубля.** В окне клиента шаблон сервера был в списке дважды: как «Как на сервере: …» и ещё раз отдельным пунктом. Теперь пункт один и называется по шаблону сервера, например **«DNS-ответ: icloud.com (по умолчанию)»**. Клиент с ним получает шаблон сервера, в том числе после того, как вы смените шаблон в настройках сервера.
- **Маршрут клиента.** Первый пункт списка маршрута назывался «Как у всех (сейчас: …)», теперь — **«По умолчанию «…»»** с названием текущего выхода. Он по-прежнему следует за выходом, выбранным для всех.

## 改动

- **客户端伪装列表不再重复。** 以前在客户端窗口中，服务器的模板会在列表中出现两次：一次是「与服务器相同：…」，另一次是单独的选项。现在只有一个选项，并以服务器的模板命名，例如 **DNS 响应：icloud.com（默认）**。选择它的客户端使用服务器的模板，在服务器设置中更换模板后也是如此。
- **客户端路由。** 客户端路由列表的第一个选项原为「与全局相同（当前：…）」，现在是 **默认「…」**，并显示当前出口的名称。它仍然跟随为所有客户端选择的出口。

## 更新

在面板中 **系统 → 更新**（从 1.4.0 起），或在服务器上运行：

    awg-router update

全新安装（Ubuntu 或 Debian，以 root 运行）：

    curl -fsSL https://raw.githubusercontent.com/r-slashslash/AWG-Router/main/install.sh | bash

## تغییرها

- **فهرست پوشش کلاینت بدون تکرار.** در پنجرهٔ کلاینت، الگوی سرور دو بار در فهرست می‌آمد: یک بار به‌صورت «مانند سرور: …» و یک بار به‌صورت گزینه‌ای جدا. اکنون فقط یک گزینه هست که به نام الگوی سرور است، مثلاً **پاسخ DNS: ‏icloud.com (پیش‌فرض)**. کلاینتی که آن را دارد الگوی سرور را می‌گیرد، حتی پس از آن‌که الگو را در تنظیمات سرور عوض کنید.
- **مسیر کلاینت.** نخستین گزینهٔ فهرست مسیر کلاینت «مثل بقیه (اکنون: …)» بود؛ اکنون **پیش‌فرض «…»** است با نام خروجی کنونی. همچنان از خروجی انتخاب‌شده برای همه پیروی می‌کند.
